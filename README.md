# TOP1 TOPUP — Demo Website

Open `index.html` in a browser to preview the site.

Included:
- Mobile-friendly gaming storefront
- Player ID field
- Diamond package selector
- Demo order creation and local order history
- Responsive dark UI

Important:
This is a front-end DEMO. It does not process real money, authenticate users, deliver diamonds, or connect to Garena/Free Fire services.
Before taking real payments or selling top-ups, use an authorized supplier/API and a compliant payment provider, and make sure the business and branding comply with applicable rules.
